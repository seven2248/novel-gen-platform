### P2-2 `local_rewrite.py:116-122` — `splitlines(keepends=True)` + `lineterm=""` 可能产生双换行

```python
diff_lines = list(difflib.unified_diff(
    selected_text.splitlines(keepends=True),
    result["rewritten_text"].splitlines(keepends=True),
    fromfile=f"a/{chapter_id}",
    tofile=f"b/{chapter_id}",
    lineterm=""
))
```

`splitlines(keepends=True)` 保留了行尾的 `\n`，但 `lineterm=""` 表示不在 diff 输出行尾额外加换行符。这两者组合是正确的（避免双换行）。不过 `cli.py:201` 的 `"".join(result["diff_lines"])` 对于 Windows 换行符（`\r\n`）可能显示异常。

**影响较小**，仅标注。
