## 3. Bug 修复

### schema_validator.py — exception 顺序 bug（P2）

`except Exception` 在 `except FileNotFoundError` 之后，导致后者永远无法触发。

**修复**：将 `except Exception` 改为 `except (json.JSONDecodeError, OSError)`，OSError 是 FileNotFoundError 的父类，正确处理文件类错误。

### LLM_CONFIG — JSON 解析失败静默 fallback（P1）

`LLM_CONFIG` 环境变量含无效 JSON 时系统静默使用默认配置，无任何提示。

**修复**：添加 `warnings.warn()` 在解析失败时输出警告信息。

## 5. BaseAgent 抽象类创建（P1 — 代码重复）

三个 agent（planner/writer/reviewer）的 `run_*` 函数结构高度相似：创建 client → 构建 context → generate → json.loads → validate。

创建 `packages/agents/src/base_agent.py`：
- `BaseAgent` 抽象类，定义 `run()` 通用流程
- 子类只需实现 `agent_type()`、`build_context()`、`build_prompt()`
- `system_prompt_name()` 返回模板文件名（可选）
- `parse_response()` + `get_fallback()` 提供统一的 JSON 解析 fallback 机制

**注意**：现有 agent 暂不重构使用 BaseAgent（风险高，等验证轮次完成后再做）。
