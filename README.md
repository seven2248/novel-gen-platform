# 小说项目整合

这个目录按“文档优先，参考仓库次之”的方式整理。

## 目录说明

- `docs/`：我方真相源，优先阅读
- `references/repos/`：本地参考仓库占位目录，保留原始结构
- `references/notes/`：参考仓库学习沉淀
- `references/snapshots/`：参考仓库同步快照
- `prompts/`：给 IDE/AI 的固定提示词
- `src/`：后续实现代码
- `tests/`：后续测试

## 当前文档分布

- `docs/plans/`：实施计划、迭代规划、计划反馈
- `docs/decisions/`：参考仓库管理方案
- `docs/context/`：项目上下文总览、交接包与补充说明

## 使用顺序

1. 先读 `docs/` 下相关 PRD、计划、决策、上下文文档
2. 再读 `references/notes/`
3. 再看 `references/repos/` 中真正相关的参考模块
4. 先输出参考对照表，再进入实现
